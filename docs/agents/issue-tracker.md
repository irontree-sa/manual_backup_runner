# Issue tracker: GitHub

Issues and planning records are tracked in the repository's GitHub issue tracker.

## Operations

- List open work: `gh issue list --repo irontree-sa/manual_backup_runner --state open`
- Inspect an issue: `gh issue view <number> --repo irontree-sa/manual_backup_runner`
- Create an issue: `gh issue create --repo irontree-sa/manual_backup_runner`
- Record investigation or implementation context in issue comments.

Use GitHub labels, assignees, milestones, and issue links for triage and dependencies.
